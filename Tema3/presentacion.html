Relación Gramática-Lenguaje

La teoría formal describe cómo las estructuras de reglas generan infinitas secuencias válidas.

Componentes Formales (Tupla)

Una Gramática Formal se define como G = (VN, VT, P, S):

  • VN: No terminales (variables sintácticas).
  • VT: Terminales (símbolos del alfabeto final).
  • P: Reglas de producción (α → β).
  • S: Axioma o símbolo inicial (S ∈ VN).

Mecanismo de generación: L(G) = {w ∈ VT* | S ⇒* w}.

Mecanismo de Derivación

Derivación de la expresión n + n * n en una gramática de aritmética:

E => E + E (Regla E -> E+E)
  => n + E (Regla E -> n)
  => n + E * E (Regla E -> E*E)
  => n + n * E (Regla E -> n)
  => n + n * n (Regla E -> n)

Aplica sustituciones sucesivas por la izquierda.

La Jerarquía de Chomsky

Clasificación concéntrica de gramáticas y su poder computacional:

Tipo Gramática Restricción en Producción Autómata Reconocedor Ejemplo Práctico
Tipo 0 Sin restricciones α → β (sin límites) Máquina de Turing Sistemas de cómputo universal
Tipo 1 Sensible al contexto |α| ≤ |β| o γAδ → γβδ Autómata Lineal Acotado Lenguajes naturales complejos / {anbncn}
Tipo 2 Libre de contexto A → β (A es un único no terminal) Autómata con Pila Estructura sintáctica de programación (JSON, XML)
Tipo 3 Regular A → wB o A → w (regular der.) Autómata Finito (DFA/NFA) Análisis Léxico (tokens, identificadores, regex)

Gramática para Dibujar (GLC)

Definición formal y modelado gráfico con el alfabeto restringido Σ = {a, c, g, t}.

Definición de Producciones en P

  • S → D
  • D → a g g a g g a g g a (Cuadrado)
  • D → a c L D t c R D t | a (Árbol recursivo)
  • D → cgatacgatgga... (Cubo oblicuo)
  • L → ggggggg (Girar izquierda 45° = 315° der.)
  • R → g (Girar derecha 45°)

La pila (c=push, t=pop) permite crear estructuras ramificadas y volumétricas.

Cadenas Derivadas y Trazados

  • Cuadrado: aggaggaggagga (Gira a la derecha 90° con 2 'g')
  • Árbol: acgggggggacgggggggatcgattcgacgggggggatcgatt
  • Cubo: cgatacgatggaggggggcgat... (Une caras paralela)

Higiene Gramatical: Ambigüedad

La presencia de múltiples árboles de derivación sintáctica genera ambivalencia semántica.

Detección en Expresiones

La regla E → E + E | E * E | n genera ambigüedad para la cadena n + n * n:

  • Interpretación 1: Suma como raíz. Equivale a n + (n * n).
  • Interpretación 2: Multiplicación como raíz. Equivale a (n + n) * n.

Resolución mediante Estratificación

Se añaden capas gramaticales para definir precedencias:

E -> E + T | T  (Operador de menor prioridad)
T -> T * F | F  (Operador de mayor prioridad)
F -> n          (Término atómico)

Garantiza un único árbol de derivación sintáctica.

Recursividad y Factorización

Dos técnicas críticas para permitir el análisis determinista descendente LL(1):

Eliminar Recursión Izquierda

Evita bucles infinitos en el parser. Para la regla recursiva E → E + T | T:

  • 1. Identificar partes: α = + T, β = T.
  • 2. Crear no terminal auxiliar E'.
  • 3. Transformación resultante:
E  -> T E'
E' -> + T E' | epsilon

Factorización por la Izquierda

Evita la indecisión del parser cuando hay prefijos comunes. Para la condicional clásica:

S -> if E then S else S | if E then S | a

Prefijo común: if E then S. Factorizado:

S  -> if E then S S' | a
S' -> else S | epsilon

Autómata de Ajedrez (PGN)

Diseño de un reconocedor sintáctico para un subconjunto de jugadas en notación PGN.

Especificación Formal

  • Subconjunto: Movimientos de peón (e4), piezas (Nf3), capturas (Bxf7, peón xe4) y jaques/mate (+, #).
  • Expresión Regular (Regex):
    [KQRBN]?x?[a-h][1-8][+#]?
  • Estados del AFD: q0 (inicio), q1 (pieza), q2 (captura), q3 (columna), q4 (fila-acep.), q5 (jaque/mate-acep.).

Diagrama del Autómata (AFD)

→
q3
→
q4
→
q5

q0 → [a-h] → q3 → [1-8] → q4 (Aceptado peón) → [+#] → q5 (Aceptado jaque)
